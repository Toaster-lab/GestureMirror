# GestureMirror
A vision-controlled robotic hand that uses computer vision, machine learning, and an ESP32 to mirror human hand gestures in real time.

## Vision for end goal:
Trying to create a ML model that can detect your gesture and mirror that on a simple bionic hand. For example when doing closing my hand, it should mirror your actions.
